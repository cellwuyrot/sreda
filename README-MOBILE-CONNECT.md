# Мобильный Connect: обновление интерфейса

Изменения подготовлены на основе архива `TrioZ-UX-UI-update.zip`. Полный проект находится в этом архиве; `mobile-connect.patch` — дополнительный патч относительно именно этой версии. Не применяйте его к другой версии без проверки конфликтов.

## Что изменено

- На мобильной главной `/connect` убрана надпись TZ.Connect, сообщества показаны строками. Поиск, уведомления, создание, вступление и счётчики сохранены.
- В нижней навигации есть профиль; его меню по-прежнему учитывает роль. Бизнес-раздел остаётся доступным, когда доступен пользователю.
- В Android-приложении прежняя кнопка Premium/VPN на главной скрыта. Путь к VPN: **Профиль → TZ ID и настройки → VPN · Надёжное соединение**. Открывается существующее окно VPN с действующей проверкой прав и нативным подключением. На сайте и в десктопном интерфейсе вход в VPN не переносился.
- В списке друзей добавлены поиск и быстрый переход в переписку. В диалогах — поиск, фильтр непрочитанных и сенсорное меню действий. При открытом диалоге нижняя панель скрывается. Сейф, защищённые диалоги, архив, папки и обработчики переписки сохранены.
- Упрощены мобильные заголовки чата и разделов настроек. Голосовая панель сообщества на мобильном экране разворачивается на весь экран, управление подписано, её закрытие не завершает подключение. Отдельно адаптировано окно личного звонка; в шапке обычного личного чата доступна кнопка аудиозвонка, видеозвонок остаётся в меню. Шифрование чата и звонок — разные механизмы: звонок не добавлен в защищённый текстовый чат.
- Поддерживается системная кнопка «назад» для панели профиля и окна VPN.

Это адаптация рабочих компонентов по мотивам согласованного макета, а не точная покадровая копия всех деталей макета. Например, дополнительные кнопки группового звонка оставлены видимыми, а не перенесены в «Ещё». Внутреннее содержимое некоторых сложных настроек сохраняет прежнюю структуру.

## Установка

1. Сделайте резервную копию базы, конфигурации, пользовательских файлов и исходников. Не заменяйте `.env`, uploads и `.git` содержимым архива.
2. В локальной копии проекта, которая соответствует исходному архиву, проверьте `git apply --check mobile-connect.patch` и затем примените `git apply mobile-connect.patch`. Патч включает исходники и новые тесты. Проверьте diff, протестируйте и отправьте в свой репозиторий. Либо перенесите нужные файлы из полного проекта вручную, проверяя конфликты.
3. Обновляйте сервер штатным процессом проекта, только после проверки ветки. Пример команды для существующей установки из инструкции предыдущего обновления (путь и имя процесса предварительно проверьте):

```bash
cd /var/www/trioz && git pull --ff-only origin main && npm ci && npm run migrate && NODE_OPTIONS="--max-old-space-size=4096" npm run build && pm2 restart trioz --update-env
```

Команда не загружает этот архив на сервер и не создаёт коммит. До её выполнения изменения должны уже попасть в нужную ветку. Не используйте `git reset --hard`. Новых миграций в этом обновлении нет; стандартная команда migrate сохранена для совместимости с обычным процессом.

4. После развёртывания обновите страницу в Android-приложении. Приложение загружает веб-интерфейс с сервера; нативные исходники здесь не менялись. Действие VPN зависит от уже установленной версии Android-оболочки и её поддержки VPN-моста. Сборка нового APK и работа сервера не проверялись.

## Проверка и ограничения

Выполнены TypeScript, ESLint, production-сборка, существующий набор тестов (2813 тестов) и четыре новых компонентных теста мобильной главной, друзей, списка диалогов и личного звонка. Полный существующий набор запускался до последних мелких правок внешнего вида и меню, новые тесты — отдельно. Реальные звонки, камера, микрофон, VPN-туннель, клавиатура и системная навигация на физическом Android-устройстве не проверялись. Необходимо проверить их перед выпуском, включая входящий и исходящий личный вызов, групповой канал, переключение камеры, сворачивание без завершения, возврат в приложение, включение и выключение VPN и пользовательские разрешения.
