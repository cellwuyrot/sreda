# Рабочий снимок TrustTunnel — не готовый релиз

Этот полный архив сохраняет проделанную работу, но не является готовым обновлением и **не предназначен для развёртывания или публикации**. Не включайте флаги пилота, не перезапускайте Endpoint и не заменяйте им серверный репозиторий. Текущая рабочая копия восстановлена из прежнего архива и архива пользовательских изменений; полная идентичность Git-дереву сервера не доказана. Сохранены полученные локальные Makefile и файлы доставки сертификата. В архиве нет пользовательских .env, ключей, keystore, node_modules и результатов сборки.

## Сделано

- Отдельный Android debug-мост, сервис и панель пилота для проектных ADMIN; в обычном Android release движок не включён. Текущий debug ограничен ARM64 и проверен только локальной сборкой и unit/UI-тестами, без запуска на телефоне и соединения с VPN.
- Серверные проверки роли проектного ADMIN и allowlist, закрытая по умолчанию выдача индивидуального профиля и проверка наличия профиля. Глобальное переключение на TrustTunnel не разблокировано; Amnezia остается прежним провайдером.
- Офлайн-подготовка индивидуальных учётных данных, зашифрованного контейнера и локальная атомарная запись с тестами. Это не доставка между серверами, не развёртывание и не проверка успешного применения.
- Дополнительно подготовлены экспериментальная локальная транзакция Endpoint с откатом и проверка снимка на VDS через OpenSSL 3 без Node; проверено только с фиктивными данными. Windows пока имеет лишь валидатор, не движок. См. `docs/TRUSTTUNNEL-TRANSACTION-WIP.md`.
- Детали, результаты и ограничения: `docs/TRUSTTUNNEL-ANDROID-SERVICE-WIP.md`, `docs/TRUSTTUNNEL-PILOT-SNAPSHOT-WIP.md` и `.codebase-memory/CHANGELOG-TRUSTTUNNEL.md`. Граф codebase-memory сохранён из пользовательского архива и не отражает изменения; требуется переиндексация.

## Остаётся до тестового развёртывания и готового обновления

1. Реализовать безопасную доставку и управление выдачей между connect и Endpoint; проверить экспериментальное локальное применение с резервным копированием и восстановлением на реальной конфигурации. Простое удаление администратора из allowlist не отзывает полученный пароль. Endpoint restart может оборвать подключения.
2. Реализовать защищённый Windows TrustTunnel-движок, в том числе привилегии, хранение профиля, управление службой и конфликт с Amnezia; собрать и проверить имеющийся канал обновлений Electron на Windows. Готового Windows TrustTunnel здесь пока нет.
3. Разрешить тестовым мобильным клиентам доступ к gateway безопасным способом: прежний allowlist пропускает лишь указанный фиксированный IPv4. Не открывать доступ всем без оценки защиты и лимитов. Существующий IPv6 firewall на Endpoint не менять без плана.
4. Проверить на устройстве VPN-permission, проверку сертификата и hostname, DNS, маршруты, утечки и выключение, конфликт с Amnezia, пересоздание Activity, жизненный цикл сервиса и режим без сети. Не утверждать работу kill switch без проверки.
5. Сверить точную рабочую ветку и файлы перед применением; перестроить индекс codebase-memory. Определить номер Windows версии выше фактически установленной и опубликованной, а затем только собирать и выпускать обновление.

Серверные тесты подключений повторно не проводились. В присланных данных root-раздел VDS имел примерно 339 МБ свободного места; не устанавливайте туда инструменты сборки и не удаляйте swap или ядра по этому архиву.
