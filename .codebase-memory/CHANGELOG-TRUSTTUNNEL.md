Обновление не меняет профиль, протокол, kill switch или серверные службы. Реальная проверка на Windows обязательна; граф памяти требует переиндексации после коммита. Подробности: docs/TRUSTTUNNEL-WINDOWS-STATUS-FIX.md.

### Маршрутизация приложений TrustTunnel — предварительная Android-реализация
- Добавлен локальный выбор приложений Android через VPN Builder, без передачи списка веб-странице или серверу; настройки применяются при следующем подключении.
- По умолчанию все приложения направляются через VPN. Пустой список приложений в режимах списков и ошибки пакетов останавливают запуск до создания VPN.
- Windows per-app split tunneling не реализован: текущее API TrustTunnel не предоставляет его. Эта работа не решает исключение Discord на Windows.
- Проверка интерфейса проведена локально; Android SDK и физические устройства недоступны, Android не собран и поведение на устройствах не проверено. См. docs/TRUSTTUNNEL-APP-ROUTING-PREVIEW.md.
