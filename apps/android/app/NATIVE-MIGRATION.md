# Нативный Android: изолированный первый этап

Это **не готовая замена приложения**. Исходный релизный запуск остаётся прежним; новые исходники находятся в `app/src/debug/java/.../nativeui` и доступны только в debug-сборке. В проекте пока остаётся WebView-клиент: он нужен для действующего приложения и сохранения его данных. Отдельный тестовый экран нарисован средствами Jetpack Compose, без WebView-интерфейса.

## Что сделано

* Нативный экран входа с существующим NextAuth (email/имя + пароль, CSRF). Сессия и cookie хранятся **только в памяти** тестового процесса; после его завершения требуется новый вход. Старая сессия и WebView-хранилище не читаются и не удаляются. OAuth / TZ ID, регистрация и восстановление пароля не перенесены. Авторизация не проверена с реальным сервером.
* Чтение групп, видимых каналов, друзей, списка личных диалогов и последних текстовых сообщений через существующие API. У защищённых диалогов и зашифрованного текста содержимое не показывается. В debug добавлены постраничная история и отправка обычного текста в каналы; ЛС остаются только для чтения. Вложения, обновления Socket.IO и многое другое не сделаны. Пустой ответ `/api/groups` не позволяет отличить отсутствие групп от отдельных серверных ошибок. Запрос этого API может запускать имеющееся на сервере автоматическое присоединение к основному сообществу.
* Настройка примерных палитр «тёмная», «светлая», «светлая тёплая», «монохромная», «монохромная светлая» с проверкой Premium/ADMIN для двух монохромных. Палитры приблизительные; оформление сообществ, цветовые схемы, фоны, Premium-эффекты и настройки чата ещё не перенесены. Существующие темы WebView не синхронизируются автоматически.
* Администратору доступен нативный обзор `/api/admin/system-stats`, другие разделы админки не перенесены. Если сервер возвращает частичные показатели или `null`, они не подменяются нулями.
* В настройках показано место VPN с честной пометкой «ещё не подключён». Новый клиент не запускает и не меняет VPN.

## Важные ограничения

* **Звонки личные и групповые, push и фоновые сценарии в нативном клиенте отсутствуют.** Остальная админка и дополнительные разделы Connect также отсутствуют. Не использовать вместо рабочей версии.
* Ключи E2EE, защищённые сообщения, файлы, черновики и данные старого WebView не перенесены. Не очищать данные и не удалять действующее приложение для проверки. Безопасная миграция ключей должна быть спроектирована и проверена до переключения пользователей.
* Нужны проверка на телефоне и тестовом сервере, проверка прав, жизненного цикла, клавиатуры и состояний ошибок. APK не является релизным и не обновляет установленное приложение: debug имеет суффикс `.debug` и другую подпись.
* Новая нативная activity экспортирована **только в debug-сборке** для прямого тестового запуска. Обычная иконка запускает существующую оболочку. Настоящий релиз и переключение launcher не выполнялись.

## Сборка и вход в тестовый экран

Открыть `apps/android` в Android Studio с JDK 17 и Android SDK 36 либо выполнить:

```bash
cd apps/android
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n ru.trioz.connect.debug/ru.trioz.connect.nativeui.NativePreviewActivity
```

Используйте тестовую учётную запись. Debug-сборка использует адрес `APP_URL` из Gradle (по умолчанию production-домен), поэтому запросы идут на настоящий сервер, если адрес не изменён при сборке. Пароль никому не отправляйте через чат. Для Firebase-приложения по-прежнему нужен собственный `google-services.json`; без него собирается вариант без push.

Проверка изолированных unit-тестов превью:

```bash
./gradlew :app:testDebugUnitTest
```

Тесты выполняются на Robolectric API 35; компиляция приложения использует SDK 36.

## Следующий тестовый этап: история и текст каналов

В debug-превью добавлены загрузка более ранних сообщений каналов и открытых ЛС, отправка обычного текста **только в каналы**, ограничение длины, отображение серверного отказа, локальный выход из памяти и отмена HTTP при уходе с экрана. ЛС/защищённые переписки не получили отправку или расшифровку. Черновик существует только на открытом экране: при уходе/закрытии процесса он теряется. Локальный выход не отзывает серверную сессию на других устройствах и не меняет старую WebView-сессию.

Если связь прервалась или сервер ответил 5xx, сообщение могло быть записано: отправка не повторяется автоматически. Проверьте последние сообщения до ручного повторения. Обновления Socket.IO, read receipts, вложения, сохранение состояния и полная семантика доставки пока отсутствуют. История проверена на локальном TLS MockWebServer, а не на реальном TrioZ-сервере.

Для staging: `./gradlew -Ptrioz.debugAppUrl=https://ваш-стенд :app:assembleDebug`. Разрешён только HTTPS-origin без пути. Этот параметр не влияет на release. Если параметр не задан, debug обращается к `https://trioz.ru`; вход и отправка имеют реальные серверные эффекты. Launcher по-прежнему **не переключён**.
