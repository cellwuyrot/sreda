# Windows: ложное сообщение об обычном VPN

На чистом ПК приложение могло показывать «Сначала отключите обычный VPN TrioZ» при отсутствии службы и адаптера. Возможная причина найдена в поиске оставшегося процесса: запускаемый для проверки PowerShell сам содержал полный путь `trioz.conf` в своей командной строке и мог обнаружить собственный PID.

Фильтр в `apps/desktop/src/main/winTunnel.ts` исключает PID выполняющейся проверки; поиск других процессов по тому же пути, а также проверки службы и адаптера сохранены. Пройдены 22 локальных desktop-теста, проверка типов и PowerShell-имитация; настоящая Windows и подключение после исправления не проверены. Для проверки пересобрать и вручную установить Windows-приложение, проверить отсутствие ложной блокировки, подключение, сеть и выключение. Специально включать обычный AmneziaWG или создавать адаптер заранее не нужно.

Приложение версии `1.2.0`, установленное ранее для теста, может не получить новую сборку автоматически под тем же номером. Сравнить с опубликованным `latest.yml`; для публичного обновления использовать номер выше уже опубликованного. Этот фикс не требует менять конфигурации серверов или глобального провайдера. Граф `.codebase-memory` не обновлён.
