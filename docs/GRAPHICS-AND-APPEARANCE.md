# Графика и внешний вид

## Изменения

- В настройках остаются обычная тёмная и премиальная «Монохром». Сохранённые светлая и Mono Lite автоматически переходят в соответствующие тёмные варианты; переключатели светлых вариантов удалены.
- Приветственная область TZ.Connect использует Topography из предоставленного материала для обычной темы и ParticleImage из материала для Monochrome. Файл `public/brand/cnnct1.png` — присланное изображение для премиальных частиц; удалены зависимость от временного blob и внешняя картинка по умолчанию. Действия «Создать пространство» и «Присоединиться» сохранены. Прежние город, планета, видео и отдельный фон день/ночь в чатах удалены.
- Сцены загружаются отдельно и только для выбранной темы. Ограничены размер буфера (около 1,2 млн пикселей) и частота отрисовки (до 15 кадров/с); плотность частиц ограничена на больших экранах. Обе сцены останавливаются в скрытом окне, учитывают reduced motion. Логотип останавливается в покое, возобновляя отрисовку при взаимодействии; форма видна и без наведения на телефоне. В отсутствие WebGL2 обычная сцена остаётся без графики, но кнопки доступны.
- Дизайн примеров регистрации, кода, чек-листа и карточки профиля адаптирован к настоящим данным и действиям приложения, без автоматических демонстрационных циклов и вымышленных счётчиков. Запись голосового сообщения сохраняет MediaRecorder, позволяет прослушать запись перед отправкой и освобождает микрофон при отмене или закрытии. Это адаптации, а не побайтовая замена демонстрационных HTML-страниц.

## Проверка и ограничения

Производственная сборка веб-приложения и автоматические тесты выполняются локально. Сцены проверялись в отдельной тестовой странице Chromium Linux на двух размерах, а также на остановку при скрытии и в reduced motion; это не проверка настоящего GPU Windows или Android. Причина ранее наблюдавшегося роста до нескольких гигабайт не установлена; предел 5% нагрузки не гарантируется. Нужны проверка длительной работы, записи и воспроизведения микрофона на устройствах, а также замеры CPU, GPU и памяти в реальном приложении. Подробности прошлых экспериментов — в `PERFORMANCE-LOCAL-INVESTIGATION.md` (там описана уже удалённая сцена).

## Установка

Изменения относятся к веб-части. Обновить исходники на сервере обычным способом, сохранить локальные конфиги и данные, выполнить `npm ci`, сборку и перезапуск процесса с существующим окружением. Миграция именно для этих изменений не нужна; сравните состояние сервера с остальными изменениями полного архива. Desktop и Android загружают веб-интерфейс; обновите страницу/перезапустите приложения и проверьте версии их оболочек. Сборка Windows/Android и работа на реальном устройстве в текущей среде не проверялись. После коммита переиндексируйте `.codebase-memory`: сохранённый граф относится к прежнему состоянию проекта.

## Исправление тестов CI

Устаревший тест удалённого фонового видео заменён проверкой механизма скрытия визуальных эффектов. Имя файла сохранено намеренно: при копировании полного архива поверх старого Git-клона прежний тест будет перезаписан. Проверка первого подключения TrustTunnel ожидает завершения асинхронной проверки другого VPN; отдельный тест подтверждает, что подключение не начинается до получения её результата. Рабочая логика подключения не изменена. При переносе полного архива в Git-клон дополнительно проверьте `git status`: файлы, удалённые из проекта, не исчезнут из клона автоматически при простой распаковке поверх него.

Правила TypeScript ESLint применяются только к файлам TypeScript, где Next.js подключает соответствующий плагин. Обновление параметров Topography перенесено из рендера React в эффект, до запуска отрисовки; правила проверок не отключались.

Локальная проверка исправления CI: 3001 тест прошёл (251 файл), в том числе три отдельных повтора исправленных тестов; 9 тестов gateway, TypeScript web и desktop, lint и production-сборка прошли. Выполнено в Linux с Node.js 24, зависимости установлены с `--ignore-scripts`, затем Prisma client сгенерирован отдельно. CI на GitHub использует Node.js 20: его результат необходимо проверить после push. Миграция на реальной БД, Android/Windows-сборки и запуск устройств не проверялись. npm также сообщил об уязвимостях зависимостей; автоматическое обновление пакетов в рамках этого исправления не выполнялось.
