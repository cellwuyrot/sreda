# Android 0.4.0: встроенный VPN и политика допуска

## Изменения

- Рабочая цепочка нативного AmneziaWG: авторизация аккаунта → публичный ключ устройства → существующий API регистрации peer → подтверждение дочерним агентом → системное разрешение Android → нативный туннель.
- Общий адаптер для кнопки TZ и окна соединения; Android сохраняет выбор сервера. Экспорт приватного профиля/QR скрыт только в Android, браузерный сценарий сохранён.
- Приватный ключ на аккаунт в локальном зашифрованном хранилище, VPN WebMessage API с точным HTTPS-origin и проверкой main frame. Старый VPN JavascriptInterface удалён.
- Статус ON только после свежего handshake, счётчики, тайм-аут соединения, foreground-уведомление и отключение. Не является проверкой фактического выхода в Интернет.
- Локальная точечная политика установленных пакетов до подключения и во время VPN, fail-closed при ошибке. JSON — единый источник runtime-списка и manifest queries; инструмент изменения списка в `apps/android/tools/vpn-policy.py`. Нет QUERY_ALL_PACKAGES и выгрузки списка приложений на сервер.
- compileSdk/targetSdk 36, актуализированная совместимая цепочка Gradle/AGP/Kotlin; backend зафиксирован в Maven Central. Учтены system bar/IME insets.
- Android CI: проверка политики, unit tests, lint, debug APK. Release требует собственного ключа; тихий fallback на debug удалён. Builder хранит постоянные конфиги за пределами очищаемого клона, формирует APK и AAB.
- Android-экран цифровой подписки показывает существующий доступ без встроенного предложения оплаты/перехода за покупкой. Play Billing не добавлен; перед модерацией обязателен аудит остальных путей навигации.
- Полная инструкция: [android-release.md](../android-release.md).

## Проверки

- Веб: **2720 тестов, 204 файла**, все прошли, включая сценарии нативного подключения, политики и отсутствия экспорта; ESLint, web TypeScript, desktop TypeScript — прошли.
- Веб production build — прошёл с тестовым окружением сборки, без подключения к production БД.
- Android: **24 unit-теста** (Robolectric/API 34): допуск, origin, валидация профиля и сохранение AWG-параметров. Тесты не поднимают настоящий туннель на телефоне.
- Python-инструмент политики: **9 тестов**, проверка исходного JSON — прошли.
- Android lint: 0 ошибок, 24 предупреждения (в том числе рекомендации по API/обновлению зависимостей). Android debug APK, release APK и AAB собраны. Release проверен с временным тестовым ключом и тестовым Firebase-конфигом: это не подписанный ключом владельца публичный выпуск и не проверка FCM-доставки. Файлы тестового ключа/конфига в архив не включены.
- Выпуск без ключа подписи отклонён ожидаемо. APK signature verification и ZIP alignment 16 KB — прошли; все восемь arm64-v8a/x86_64 ELF-библиотек имеют LOAD alignment не меньше 16 KB. Это не испытание на 16 KB устройстве.
- При одновременных тяжёлых сборках sandbox исчерпал память, Gradle был остановлен OOM. Повторная итоговая Android-проверка прошла при последовательной сборке; серверу сборки нужна достаточная RAM. Это не ошибка теста продукта.

## Границы результата

Нет физического Android-устройства/живого теста TUN, NAT, DNS, IPv6, переключения Wi-Fi/LTE, энергосбережения и реальной FCM-доставки. Эти пункты — обязательный приёмочный чек-лист перед выпуском, а не заявленная пройденная проверка. Подписи production, Firebase и публикация Play выполняются владельцем с его учётными данными.

Нет kill switch/always-on: после остановки туннеля возможна обычная сеть. Проверка заданных приложений не доказывает перехват трафика, не защищает гарантированно от ТСПУ, не является серверной аттестацией и может обходиться изменённым клиентом/другим профилем пользователя.

Логика создания/назначения партнёрских проектов, мониторинг, банковские операции и серверные права подписок не изменены. Правки и журнал обновления размещены в `docs`, новые QA-изображения, логи сборок, SDK, APK/AAB и секреты в исходный архив не добавляются.
