# Обновление реакций: мягкий объём и общий выбор эмодзи

## Что изменено

- Заменены все **25 SVG** в `apps/web/public/emojis/trioz` на авторскую векторную графику с градиентами, бликами и более выразительной мимикой. Первые 10 образцов соответствуют согласованному концепту, остальные 15 выполнены в том же стиле. Внешние CDN, стикерпаки и новые production-зависимости не используются.
- Имена файлов, Unicode-значения и порядок набора сохранены. Миграции БД нет; старые реакции и счётчики не переписываются. В URL добавлена версия `?v=2`, чтобы браузер не оставлял старые SVG из кеша.
- Личные и групповые чаты используют общий `ReactionPill`: глиф 24 px, счётчик, состояние собственной реакции, клавиатурный фокус и краткий отклик на нажатие. В новостях тот же компонент отображает **только счётчик**, без фиктивной кнопки отправки реакции.
- Тёмная тема — бирюзовый акцент, светлая — фиолетовый. На устройствах с грубым указателем (`pointer: coarse`, в том числе обычные телефоны) высота области нажатия не меньше 44 px.
- Общее окно выбора: поиск по русским/английским названиям, синонимам и символам; вкладки «Все», «Недавние», «Сообщество»; пустые состояния; стрелки, Home/End и Escape. При закрытии через Escape или выборе в композере фокус возвращается на кнопку.
- «Недавние» сохраняются только в localStorage этого браузерного профиля, максимум 12 записей. На сервер и между устройствами история не отправляется. Есть «Очистить недавние». Блокировка/повреждение localStorage не мешает выбору; в таком случае история может работать только в памяти открытого окна.
- Пользовательские эмодзи сохраняют строки `:name:`, изображения и текущие проверки прав. Недавний пользовательский эмодзи показывается только там, где в текущем наборе совпадает его ID и имя: набор другого сообщества не подмешивается. В истории нет URL изображений, сообщений или сведений о пользователях.
- Незнакомые эмодзи остаются Unicode-глифами платформы. Составные ZWJ-последовательности, модификаторы оттенка кожи и флаги не разрезаются на части для замены. При ошибке загрузки встроенного SVG также используется Unicode.
- Меню учитывает размеры viewport, изменения размеров и прокрутку; устранён конфликт с фиксированной шириной кнопок родительского тулбара. Внутри списка есть ограниченная прокрутка.
- Обновление общих рисунков действует и в тексте сообщений, поскольку там уже используется `TriozText`. Пользовательские эмодзи, вложения и форматирование остаются в прежнем обработчике.

## Где что настраивать

| Файл | Назначение |
|---|---|
| `apps/web/public/emojis/trioz/*.svg` | 25 векторных рисунков |
| `apps/web/src/lib/reactionEmoji.ts` | Набор Unicode → файл, названия, синонимы поиска, разбор локальной истории, версия ресурсов |
| `apps/web/src/components/ui/TriozEmoji.tsx` | Глиф, текст, общий picker, история, позиционирование и кнопка открытия |
| `apps/web/src/components/ui/ReactionPill.tsx` | Визуальная кнопка/счётчик реакции |
| `apps/web/src/app/globals.css` — блок `REACTIONS-V2` | Размеры, обе темы, фокус, touch и reduced motion |

При дальнейшей замене SVG повысить `REACTION_EMOJI_ASSET_VERSION` в `reactionEmoji.ts`. Не менять существующие Unicode-строки ради редизайна: сервер различает реакции по их исходным значениям. Новые значения добавлять отдельно, с проверкой API и тестами.

## Границы изменения

Платёжные операции, подписки, VPN, роли, серверные проверки доступа, создание партнёрских проектов, мониторинг, socket-события и API реакций не изменены. Сохранена ранее согласованная правка Android CI: не запрашивать устаревший SDK-пакет `tools`, использовать Java 17 и закреплённый Ubuntu runner.

Постоянной анимации нет. Короткий CSS-отклик отключается при `prefers-reduced-motion`. Загрузка чужих наборов из Интернета и синхронизация истории между аккаунтами не добавлялись.

## Обновление на сервере

Сначала влить изменения в ветку, которую получает production. Для существующего чистого checkout и настроенного Node.js проекта:

```bash
cd /var/www/trioz &&
git pull --ff-only &&
npm ci &&
NODE_OPTIONS='--max-old-space-size=4096' npm run build &&
pm2 restart trioz --update-env
```

Отдельная миграция БД, пересборка Android APK или переустановка дочерних VPN-узлов для этого изменения не нужны: оболочки загружают обновлённую веб-часть. После публикации обновить страницу/перезапустить оболочку, чтобы получить новый JavaScript и CSS.

## Приёмка

1. В личной переписке и группе поставить и снять реакцию; проверить счётчик и второе окно пользователя.
2. Перезагрузить страницу: серверные реакции сохранены, «Недавние» доступны в том же браузерном профиле.
3. Найти «сердце», `fire`, `🔥`; проверить пустой поиск и очистку строки.
4. Проверить свой набор сообщества и отсутствие его недавних эмодзи в другом сообществе.
5. Проверить тёмную/светлую тему, узкий экран, фокус, Escape и системное уменьшение анимации.
6. Проверить неизвестные Unicode, оттенки кожи, составные эмодзи и ошибки загрузки SVG.
7. Физический Android/WebView и реальная многопользовательская доставка проверяются отдельно после развёртывания; локальный Chromium-стенд не заменяет проверку production API.

Результаты автоматических и визуальных проверок приведены в `docs/updates/chat-reactions-v2-checks.md`. Скриншоты, локальный стенд, npm-кеш, node_modules и сборочные логи в исходный архив не включены.
