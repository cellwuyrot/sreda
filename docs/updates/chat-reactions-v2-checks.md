## Визуальные и браузерные проверки

Изолированный локальный стенд использует **настоящие React-компоненты, SVG и собранный CSS проекта**, но демонстрационные сообщения и callback вместо production API.

В Chromium выполнены **34 проверки**, ошибок JavaScript не обнаружено:

- Ширины **320, 390, 768 и 1200 px**, тёмная и светлая тема — 8 сочетаний.
- Нет горизонтального переполнения документа или битых изображений.
- Открываемое меню композера остаётся в пределах проверенных viewport; Escape его закрывает.
- Работают поиск, запись и очистка истории, переключение собственного счётчика реакции.
- Вложенный тулбар не сжимает вкладку «Недавние» до прежних 28 px.
- При `prefers-reduced-motion` нет transition-анимации реакции.
- Дополнительно эмулировано мобильное окружение с touch: области реакций и вариантов выбора не меньше 44×44 px, окно помещается по ширине.

## Что не заявляется проверенным

Это не многопользовательская end-to-end проверка развёрнутого сервера. База, socket-доставка реальным пользователям, физический Android/WebView, экранная клавиатура устройства, Safari/iOS и все сочетания системного масштабирования требуют приёмки после публикации. Существующие API/проверки прав/формат хранения реакций не менялись.

Нативный Android-код не изменялся и его Gradle-сборка в рамках этого изменения повторно не выполнялась. В полном архиве сохранена ранее согласованная правка workflow установки Android SDK; результат нового запуска GitHub Actions следует смотреть в самом репозитории.

В архив не включены node_modules, `.next`, локальный Chromium-стенд, Playwright, скриншоты, логи, тестовые окружения и ключи. Прочие данные исходного архива сохранены.
