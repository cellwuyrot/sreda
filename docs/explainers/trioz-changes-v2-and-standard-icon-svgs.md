# trioz-changes-v2 + индивидуальные SVG-иконки

Этот документ объясняет два независимых изменения, вошедших в один PR:

1. **Обновление `trioz-changes-v2`** — распаковка и применение готового пакета из
   `docs/explainers/trioz-changes-v2.zip` (роли, окно настроек группы, баны, единый набор фавиконов).
2. **Индивидуальный SVG-дизайн стандартных иконок** — по аудиту
   [`docs/explainers/standard-icons.md`](./standard-icons.md) нарисован собственный SVG для каждой
   «стандартной» иконки (эмодзи ОС, символы Unicode, `lucide-react`).

---

## Background

> [!NOTE]
> Раздел для тех, кто впервые видит этот проект. Если вы уже в контексте — переходите к «Intuition».

**Что за проект.** `trioztest` — монорепозиторий на npm workspaces: веб-приложение (`apps/web`, Next.js +
Prisma) и десктоп-обёртка (`apps/desktop`, Electron с автообновлением через `electron-updater`). Модуль
«Connect» — это командный мессенджер с группами (сообществами), каналами разных типов (текст, голос, задачи,
вики, календарь) и ролями участников.

**Роли в группе.** У участника группы есть роль: `OWNER` (владелец), `ADMIN`, `MODERATOR`, `MEMBER`. Права
проверяются на сервере в route-хендлерах под `apps/web/src/app/api/groups/[id]/...`. Схема данных описана в
`apps/web/prisma/schema.prisma` — Prisma генерирует по ней клиент и миграции БД.

**Иконки в проекте.** Уже существует единая система иконок `apps/web/src/components/ui/ConnectIcons.tsx`:
это React-компоненты, рисующие инлайновый `<svg>` через общий `IconBase` со стилем
`viewBox 0 0 24 24`, `stroke="currentColor"`, `stroke-width≈1.9`, скруглённые концы. Часть иконок берётся из
PNG в `apps/web/public/icons/` (56 файлов, канон 256×256). Помимо этой системы в коде до сих пор встречаются
«стандартные» иконки: системные эмодзи (📁, 🗑, ⚙…), текстовые символы Unicode (✕, ←, ▸…) и иконки библиотеки
`lucide-react` (в двух файлах). Их полный аудит с точными местами и размерами — в
[`standard-icons.md`](./standard-icons.md).

**Узкий контекст этого PR.** Обновление `trioz-changes-v2` чинит давнюю проблему прав («Админа» нельзя было
выдать), добавляет полноэкранное окно настроек группы, систему банов и единый набор фавиконов/значков
десктопа. Вторая часть — подготовка индивидуального SVG на каждую стандартную иконку, чтобы в дальнейшем уйти
от системных эмодзи/символов к единому фирменному набору в стиле `ConnectIcons`.

## Intuition

**Часть 1 — обновление.** Пакет `trioz-changes-v2.zip` — это «готовые файлы, скопировать по тем же путям с
заменой». Обновление применено именно так: архив распакован поверх дерева репозитория, после чего сам архив
удалён (как это делалось для прошлых пакетов вроде `tz-connect-update.zip`). Ключевая идея багфикса ролей — на
маленьком примере: раньше `PATCH .../members/[memberId]` принимал только `MODERATOR`/`MEMBER`, поэтому запрос
«сделать Админом» молча отклонялся. Теперь проверка построена на **иерархии рангов**: владелец может выдать
любую роль ниже себя, админ — только роли ниже себя, и никто не может менять себя или равного/старшего.

**Часть 2 — иконки.** Представьте, что «закрыть» в приложении рисуется тремя разными способами: символом `✕`,
символом `×` и компонентом `X` из `lucide-react`. Выглядят они по-разному и зависят от шрифта ОС. Идея —
нарисовать **один** аккуратный `close.svg` в общем стиле проекта и свести к нему все три варианта. Так для
каждой стандартной иконки из аудита появляется ровно один фирменный SVG.

> [!TIP]
> Все новые SVG используют `stroke="currentColor"`. Это значит, что иконка принимает цвет текста родителя и
> автоматически работает в светлой и тёмной теме — ровно как компоненты `ConnectIcons`.

Пример — иконка «назад» (`←`) размером 24×24:

```svg
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.9"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M20 12H5" />
  <path d="M11 6l-6 6 6 6" />
</svg>
```

## Code

### 1. Применённое обновление (`trioz-changes-v2.zip`)

Багфиксы прав и передача владения — серверные route-хендлеры:

```text
apps/web/src/app/api/groups/[id]/members/[memberId]/route.ts   # PATCH: выдача ADMIN + иерархия ролей
apps/web/src/app/api/groups/[id]/route.ts                       # PUT: ADMIN больше не исключён из проверки прав
apps/web/src/app/api/groups/[id]/transfer-ownership/route.ts    # новый: передача группы (транзакция + аудит)
apps/web/src/app/api/groups/[id]/bans/route.ts                  # новый: GET список / POST бан
apps/web/src/app/api/groups/[id]/bans/[banId]/route.ts          # новый: DELETE разбан
apps/web/src/app/api/invites/[code]/route.ts                    # забаненный не входит по инвайту (403)
```

Новая модель банов в схеме Prisma:

```prisma
model GroupBan {
  // причина, кто забанил, дата; уникальность (groupId, userId)
}
```

> [!IMPORTANT]
> Для банов нужна миграция БД: `npx prisma migrate dev -n group_bans` (или `npx prisma db push`).
> Это единственный шаг обновления, который выполняется вне git.

UI и десктоп:

```text
apps/web/src/components/connect/GroupSettingsModal.tsx  # новый: полноэкранное окно настроек группы (743 строки)
apps/web/src/components/connect/GroupDialogs.tsx        # старый модал удалён, реэкспорт нового (импорты не меняются)
apps/desktop/package.json                               # версия 0.1.2 → 0.1.3 для electron-updater
scripts/generate-icons.py                               # новый: генерация фавиконов/значков из PNG с прозрачностью
apps/web/public/{favicon.*, icon-192, icon-512, apple-touch-icon}  # перегенерированный набор
apps/desktop/{build,resources}/{icon,tray,trayTemplate}.*          # значки десктопа
```

Полное описание — во включённом в пакет `docs/changelog.md` (в корне репозитория). Сам архив
`docs/explainers/trioz-changes-v2.zip` после применения удалён.

### 2. Индивидуальные SVG-иконки

Всё сгенерировано скриптом-источником (по аналогии с `scripts/generate-icons.py` из пакета):

```text
scripts/generate-standard-icon-svgs.py         # источник: данные иконок + рендер SVG/README/preview
apps/web/public/icons/svg/*.svg                # 26 индивидуальных иконок
apps/web/public/icons/svg/README.md            # таблица: файл → заменяемый глиф → места в коде
apps/web/public/icons/svg/preview.html         # галерея-предпросмотр всех иконок
```

В скрипте каждая иконка описана декларативно, а разметка собирается единым шаблоном — так гарантируется общий
стиль:

```python
ICONS = [
    {"name": "close", "glyph": "✕ / × / X", "cat": "Символ Unicode / lucide",
     "purpose": "Закрыть / убрать", "body": ["M6 6l12 12", "M18 6L6 18"],
     "uses": ["MessageArea.tsx:1438", "TasksPanel.tsx:810", "Navbar.tsx:316 (lucide X)", ...]},
    # ... ещё 25 иконок
]
```

Покрыты все три категории аудита: **13 эмодзи** (📁 📂 ➕ 📄 🖼 📎 🗑 ⚙ 🔔 ✏ 🗂 ⭐ 🔒),
**6 символов Unicode** (▸ ▾ ✕/× ✓ → ←) и **9 иконок lucide-react** (Search, Sun, Moon, SquarePen,
ChevronDown, LogOut, X, Menu, Send). Совпадающие по смыслу глифы сведены к одному SVG: `▾` и lucide
`ChevronDown` → `chevron-down.svg`; `✕`/`×` и lucide `X` → `close.svg`. Итого **26 файлов**.

## Verification

**Обновление.** По прямой просьбе владельца («проверки не нужны, оно работает») пакет применён дословно,
полная пересборка не запускалась. Структурная целостность применения проверена: версия десктопа поднялась до
`0.1.3`, модель `GroupBan` присутствует в `schema.prisma`, новые route-файлы (`bans`, `bans/[banId]`,
`transfer-ownership`) и `GroupSettingsModal.tsx` на месте, а файлы из ранее применённого пакета
`trioz-fixes-tech.zip` совпадают с деревом (обновление не откатывает прошлые изменения).

**Иконки.** Проверено двумя способами:

1. **XML-валидность** — все 26 SVG успешно разобраны парсером (`xml.dom.minidom`).
2. **Визуальный рендер** — каждый SVG растеризован (`cairosvg`) и собран в общий контакт-лист; все иконки
   читаемы, узнаваемы и выдержаны в едином штрихе.

Ручная проверка (шаги для QA):

1. Откройте `apps/web/public/icons/svg/preview.html` в браузере — увидите галерею всех 26 иконок с подписями
   «какой глиф заменяет».
2. Сверьте таблицу в `apps/web/public/icons/svg/README.md` со списком в `docs/explainers/standard-icons.md` —
   каждая строка аудита должна иметь соответствующий SVG.
3. Для проверки обновления: `npx prisma migrate dev -n group_bans`, затем `npm run dev`, откройте окно настроек
   группы и попробуйте выдать роль «Админ» и забанить участника.

## Alternatives

**Как оформить иконки** — выбран вариант «отдельные `.svg`-файлы + генератор». Рассмотренная альтернатива:

| Отдельные SVG-файлы (выбрано) | React-компоненты в `ConnectIcons.tsx` |
|---|---|
| ✅ Буквально «индивидуальный SVG на иконку», как просили | ✅ Сразу используются в JSX с `tone`/`glow` |
| ✅ Виден предпросмотр, легко отдать дизайнеру | ✅ Одна система вместо файлов + компонентов |
| ✅ Не трогает рабочий код (нулевой риск регрессий) | ❌ Требует правок 40+ файлов — большой diff и риск |
| ❌ Для использования нужен ещё шаг подключения | ❌ Выходит за рамки просьбы «подготовить дизайн» |

**Как применить обновление** — выбрана распаковка архива «как есть». Альтернатива — вручную переносить куски
кода из архива, сверяя с текущим деревом. Плюс: точечный контроль. Минус: медленно и рискованно, тогда как
автор пакета явно указал «скопировать файлы по тем же путям с заменой».
