# Незакрытые задачи (заметка для агентов)

Обновлено 29.07.2026. Три задачи, что стояли здесь раньше, закрыты — ниже
коротко, чем именно, чтобы следующий агент не переделывал сделанное.

## Закрыто

**1. Выдача VPN-доступа из админки.** `POST /api/admin/vpn/peers` + форма в
`/admin/vpn` («Выдать доступ»): логин получателя, публичный ключ на 44 символа,
метка. В ответ панель показывает готовый блок `[Interface]/[Peer]` для
клиентского профиля. Приватный ключ по-прежнему не принимается: тело с полем
`privateKey` отклоняется с 400. Один аккаунт — один пир, повторная выдача
заменяет ключ.

**2. Правая панель: три состояния по кругу, один вход в участников.**
`usePanelView` в `components/connect/panelCollapse.tsx`: участники → разделы →
скрыто. Одинаково в `SectionsPanel` и `ModulesPanel`, то есть во всех группах.

История этого места стоит того, чтобы её знать, иначе она повторится:

1. в #426 я добавил в панель свой список участников;
2. оказалось, что список участников уже есть — `MembersPanel`, её открывала
   кнопка «Участники» внизу списка каналов. На экране оказывались две панели;
3. в #431 я убрал свой режим — но остался вопрос, почему участники живут в
   отдельной кнопке, а не рядом с разделами;
4. итог: кнопка «Участники» убрана (и внизу каналов, и в меню шапки), список
   вынесен в `MembersList` и показывается в правой панели.

**Правило.** Список участников рисует только `MembersList`. Появится третье
место, где нужны участники — импортировать его, а не писать свой.

**3. Свёрнутый вид — полоса 60px.** Не нулевая ширина: полоса целиком является
кнопкой разворота, поэтому панель нельзя потерять и не нужен язычок, наезжающий
на чат. Ширина одна на оба компонента — `COLLAPSED_WIDTH`.

Важное: правую колонку рисуют ДВА компонента — `SectionsPanel` (блоковый режим:
главное сообщество и группы с включёнными разделами) и `ModulesPanel` (обычные
группы, «рабочие модули»). Логика показа была в каждом своя, копией, и копии
разъезжались — отсюда «в TZ Connect одно, в других другое».

**Правки показа панели делать только в `panelCollapse.tsx`.** Копия этой логики
в двух файлах уже дважды приводила к расхождению.

Ещё одна ловушка: колонка `ModulesPanel` раньше не рисовалась, если в группе нет
ни одного модуля. Теперь её заголовок — единственный вход в участников, поэтому
условие снято; прячется она только когда нет ни модулей, ни права смотреть
участников (главное сообщество для обычного участника, `hideMembersForMain`).

## Что осталось

По VPN — генерация ключа в десктоп-клиенте и автодеплой: см.
`docs/explainers/vpn-next-steps.md`, там же причины, по которым автодеплой нельзя
включать до переноса голосового состояния в Redis.

## Правила, на которых падал CI

- `react-hooks/immutability` запрещает присваивание значениям, объявленным вне
  компонента, — включая `window.location.href`. Использовать `location.assign()`.
- линт настроен как `eslint src/`, поэтому `server.ts` и `apps/desktop` им не
  проверяются, но ошибки типов в них всё равно всплывают на `next build`.
- перед пушем: синтаксическая проверка изменённых файлов и побайтовая сверка
  каждого с текущим `main` — локальная копия в песочнице уже дважды отставала.
