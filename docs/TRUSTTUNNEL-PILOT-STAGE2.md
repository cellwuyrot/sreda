Архив содержит полную рабочую копию исходников, но функция подключения TrustTunnel ещё не реализована целиком. Не копировать поверх серверного репозитория, не включать пилот и не выпускать приложения. Если предыдущий промежуточный архив уже перенесён на сервер, сначала выяснить, было ли развёртывание и перезапуск; не выполнять откат вслепую.

## Данные от владельца

На момент проверки у установленного Endpoint задан `credentials_file`, файл существует с правами 0640, содержит одну запись `client`; секция metrics не задана. Реальные имена, пароли и содержимое файла не передавались. Эти наблюдения не считаются автоматически подтверждёнными навсегда.

## Выполнено

`apps/vpn/src/trusttunnel_credentials.py` — изолированная чистая логика: создаёт случайный непрозрачный логин и 256-битный пароль; готовит полный текст credentials.toml с выделенным управляемым разделом, не изменяя исходные записи; принимает полный список управляемых доступов и может подготовить удаление или замену. Проверяет TOML, формат, дубликаты, конфликты с существующими пользователями, служебные метки. Не открывает файлы, не хранит данные, не отправляет запросы, не пишет логи и не перезапускает службы. Это не работающее подключение и пока нигде не вызвано.

`apps/vpn/src/trusttunnel_credentials_test.py`: восемь локальных тестов с фиктивными данными. Запуск из корня: `python3 -m unittest apps/vpn/src/trusttunnel_credentials_test.py -v` (Python 3.11+). Ни сеть, ни настоящие файлы не используются. Пройдено 8/8 в изолированной среде. На предыдущем этапе также пройдено 13 тестов прав и блокировок API с моками.

## Ещё требуется до работающего пилота

- Защищённое хранилище и привязка к пользователю, отзыв/ротация в БД; безопасная передача от главного сервера к узлу без секретов в Git, аргументах команд и логах; аутентификация и контроль повторных запросов.
- Атомарная запись с сохранением владельца/группы/прав, управлением конкурентностью, резервным копированием, проверкой, восстановлением и контролируемым применением. Сам данный модуль не выполняет запись.
- Endpoint v1.1.0 документирует SIGHUP для TLS hosts, а не для обновления credentials. Возможный управляемый restart может оборвать действующие TrustTunnel-подключения; режим применения требует отдельной проверки и согласования. Никаких перезапусков сейчас не выполнять.
- Endpoint metrics сейчас не включены. Нужны защищённые метрики и сопоставление трафика с аккаунтом, прежде чем объявлять глобальный провайдер готовым.
- Android и Windows TrustTunnel SDK/адаптеры, UI, поставка APK/инсталлятора и проверки их сборки. Действующая IPv4 allowlist gateway не содержит меняющийся мобильный адрес. Не открывать порт всем без отдельного решения.
- Глобальный провайдер остаётся заблокированным; нельзя переименовывать этот архив в готовый релиз.
