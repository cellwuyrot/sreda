# Подготовка локального сохранения credentials: не готовый пилот

`apps/vpn/src/trusttunnel_atomic_store.py` — Linux-only библиотека Python 3.10+ с локально включённым TOML-парсером при отсутствии `tomllib` для локального сохранения подготовленного TOML при совпадении SHA-256 исходного файла. Код пока не подключён к приложению, пользователю, узлу или systemd и не выполнялся на серверах.

Проверяются синтаксис TOML, отсутствие дублирующихся usernames, владелец каталога и файла (должен совпадать с владельцем процесса), ограниченные права, тип и количество ссылок, наличие симлинков, размер и исходная контрольная сумма. Файл создаётся в той же директории и переименовывается атомарно; владелец, группа и разрешения сохраняются. Для применений необходима кооперативная блокировка со стороны всех редакторов файла; посторонний редактор, игнорирующий блокировку, может нарушить защиту от конкурентных изменений. Каталог и промежуточные директории должны быть доверенными. Если fsync директории завершится ошибкой после переименования, `StoreCommitUncertain` обозначает неопределённый результат; повторять операцию без проверки нельзя.

Локальные тесты во временном каталоге: `python3 -m unittest apps/vpn/src/trusttunnel_credentials_test.py apps/vpn/src/trusttunnel_atomic_store_test.py`. Тесты не изменяют серверы и не проверяют работу сети. Сценарии проверяют фиктивные credentials, права, ссылки, совпадение контрольной суммы и неопределённый результат после rename.

Не реализованы защищённая передача и хранение учётных данных на connect, привязка пользователей и отзыв, проверенная резервная копия, восстановление, проверка процесса после перезапуска, журнал аудита и интеграция Android/Windows. Код нельзя разворачивать как готовую функцию или вручную запускать на реальных credential-файлах. Применение конфигурации на Endpoint может прервать существующие соединения и требует отдельного плана восстановления.
