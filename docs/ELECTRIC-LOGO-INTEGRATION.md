## Реализация

- `apps/web/src/components/connect/CnnctElectricLogo.tsx`, `CnnctElectricLogo.css`, `electricLogoConfig.ts` — оригинальные шейдеры, управляемый WebGL2-контекст и параметры из задания. `ConnectWelcome.tsx` показывает логотип в обеих тёмных темах.
- `useElectronWindowActivity.ts` и IPC в `apps/desktop/src/main/{mainWindow,ipc}.ts`, `src/preload/index.ts`, `src/shared/constants.ts`, `apps/web/src/lib/desktop.ts` — проверка активности окна через ограниченный API без выдачи ipcRenderer. `contextIsolation` и `nodeIntegration` не менялись.
- Квадратный canvas ограничен CSS-размерами `min(420px, 75vw, 60vh)`. DPR ограничен 2 и бюджетом 4 000 000 пикселей: `min(devicePixelRatio, 2, sqrt(4000000 / (width * height)))`.
- Один таймер планирует следующий кадр, один RAF выполняет рисование; интервал не короче 1/60 секунды. При потере фокуса, сворачивании, скрытии, выходе из видимой области или включённом reduced-motion кадры прекращаются, таймер/RAF отменяются. Возобновление не пересоздаёт обычный контекст и не прибавляет время паузы.
- ResizeObserver и IntersectionObserver контролируют размер и видимость. При потере контекста — статичное изображение, при восстановлении создаются ресурсы заново; при ошибке картинки — текстовый fallback. При размонтировании отсоединяются слушатели и наблюдатели, отменяются задачи и освобождаются ресурсы WebGL.
- Разметка внутренних промежуточных данных изображения создаётся один раз при загрузке; она не является дополнительным видимым анимированным canvas.

## Микроанимации

Реализованы лёгкие адаптации идей из обзора, а не копии восьми компонентов React Bits: Spring Check и Animated List (`TasksPanel.tsx`), Code Slots (`globals.css`, экран входа), Voice Pill (`VoiceRecorder.tsx`, `RecordingWaveform.tsx`), Rubber Segment (`PremiumInfoModal.tsx`), Status Mark (`TasksPanel.tsx`), Swipe Toast (`DMPanel.tsx`), Fade Content (`ConnectWelcome.tsx`). Анимации интерфейса короткие и учитывают reduced-motion. Аудиоиндикатор использует уже открытый поток записи, дополнительного запроса микрофона нет; работает только при активной записи, видимом и сфокусированном окне.

## Регистрация

Убраны обязательная цифра и требование начинать с латинской буквы. Логины из букв Unicode, цифр, `_` и `-` могут состоять только из букв или только из цифр. Сохранены длина 6–20, запрет пробелов, `@` и прочих знаков, а также зарезервированное имя `everyone` — для совместимости авторизации, адресов и упоминаний. Это не произвольная строка без ограничений. Сервер и клиент используют единый валидатор; обработка упоминаний адаптирована к Unicode. Существующее правило Premium для смены логина без цифр в настройках не отменялось: к новой регистрации оно не относится.

## Оставшиеся ограничения и развёртывание

**Важно:** в существующем Electron-проекте `backgroundThrottling: false` уже использовался, в том числе для голосового overlay. Эта настройка сохранена во избежание непроверенной поломки связи. Поэтому буквальное требование «не отключать backgroundThrottling» пока не выполнено; остановка логотипа реализована отдельно через IPC и наблюдатели. Для изменения настройки нужна отдельная проверка фоновых звонков, overlay и окон в реальном Electron.

Windows/Electron, аппаратный GPU, Alt+Tab, сворачивание и восстановление окна, реальные звонки и Android-сборка в этой среде не проверялись. Проверьте их на целевой машине вместе с CPU, GPU, GPU-памятью и повторным открытием окна. 5% GPU не гарантируется. Нельзя объявлять оптимизацию завершённой по результату программного WebGL.

Обновите серверную веб-часть из проекта, установите зависимости по lock-файлу (`npm ci`) и соберите её (`npm run build`); обновите desktop-сборку, чтобы получить новый IPC. Для старого desktop используется ограниченный fallback по доступным событиям окна. В этой задаче миграций базы нет. Не размещайте реальные env-файлы, ключи и токены в репозитории. Граф `.codebase-memory` не переиндексирован и может быть устаревшим.
