# Платежи: удаление блоков CloudPayments из админки

На странице `/admin/payments` удалены карточки «CloudPayments — интернет-эквайринг» из вкладок **Premium** и **Ускоренный интернет**: поля Public ID/API Secret, переключатели, информация о webhook и кнопки настройки уведомлений.

Удалены неиспользуемые обработчик настройки уведомлений и состояния этих двух карточек.

Сохранены:
- стоимость и валюта обеих подписок;
- реквизиты СБП;
- наследование реквизитов Premium для ускоренного интернета;
- оплата по банковским ссылкам;
- настройки бизнеса, включая бизнес-эквайринг;
- шаблоны счетов и общая кнопка сохранения.

Это **удаление блоков интерфейса**, а не отключение платёжной интеграции. Существующие настройки, ключи в БД, обработка платежей, webhooks и подписки не удалены и не отключены. Сохранение оставшихся полей не сбрасывает ранее настроенный эквайринг.

## Проверки

4 регрессионных теста в `apps/web/src/components/admin/AdminPaymentsPage.test.tsx`: отсутствие блока в обеих вкладках, сохранность других вкладок, сохранение настроек без отключения эквайринга/удаления ключей.

Команда:

```bash
npm run test -w apps/web -- --run src/components/admin/AdminPaymentsPage.test.tsx
```

Итоговые результаты ESLint, сборки и тестов: `docs/test-reports/admin-payments-ui-validation.txt`.

## Обновление PM2

Архив содержит предыдущие исправления чатов и VPN. Перенесите исходники, не заменяя серверные `.env*`, пользовательские загрузки и конфигурацию PM2/nginx.

Если предыдущее обновление чатов ещё не устанавливалось, сначала примените его миграцию по `docs/community-chat-update.md`. **Для удаления блоков платежей отдельной новой миграции нет.**

После обновления исходников:

```bash
cd /var/www/trioz
npm run build
```

Только после успешной сборки:

```bash
pm2 restart trioz
pm2 save
```

Остальные процессы PM2 не перезапускаются. Изменения в этом архиве не устанавливались на production-сервер.
