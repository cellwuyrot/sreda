# Личная страница со стеной и подписками + чёрный экран десктопа

Дата: август 2026. Маркеры в коде: `FIX-BLANK2` (десктоп), `PROFILE-WALL` (профиль).

## 1. Чёрный экран десктопного клиента

### Причина

Electron кешировал **сам HTML-документ**. В закешированном HTML лежит список
чанков той сборки, при которой он был сохранён. Сервер выкатывается чаще, чем
обновляется клиент, и после выката имена файлов `/_next/static/chunks/<hash>.js`
другие — старый документ грузит несуществующее дерево и не отрисовывает ничего.
Окно остаётся чёрным до ручной очистки кеша.

Три существовавших сторожа промахивались:

1. `invalidateCacheOnVersionChange()` — реагировал только на смену версии
   **клиента** (`app.getVersion()`). Сервер обновляется отдельно.
2. `watchStaleAssets()` — ждал 404 на `/_next/static/*`. Но старый HTML и старые
   чанки лежат в кеше вместе (`immutable`, год), сетевого запроса нет вовсе.
3. `watchBlankRender()` — считал страницу живой при любом `svg`/`img` в DOM, а
   упавшее дерево React оставляет каркас с иконками.

### Что сделано

- `preventDocumentCaching(appOrigin)` — документ (`mainFrame`) запрашивается с
  `Cache-Control: no-cache`. Статика по-прежнему кешируется: тормозить запуск
  ради этой болезни не нужно, лечится именно документ.
- `rendererLooksAlive(win)` — признак живого интерфейса теперь текст и элементы
  управления (`button, a[href], input, textarea, canvas`), а не наличие картинки.
- `startCacheMaintenance(win)` — тихая проверка раз в 15 минут: чистит кеш и
  кеш кода без перезагрузки; если интерфейс не отрисован — перезагружает с
  очисткой. Останавливается в `before-quit`.

`clearStorageData` не вызывается нигде: это снесло бы cookie входа.

## 2. Личная страница

### Навигация

Имя в шапке ведёт в `/profile` (раньше — в уведомления). Колокольчик рядом
остался на месте; в выпадающем меню «Мой профиль» стоит первым пунктом.

### Данные

Новые таблицы (миграция `20260920000000_profile_wall`):

| Таблица | Смысл |
| --- | --- |
| `Follow` | подписка «кто → на кого», пара уникальна |
| `WallPost` | запись стены: заголовок, текст, обложка, вложения, закрепление, просмотры |
| `WallComment` | комментарии к записи |
| `WallPostView` | уникальные просмотры, чтобы счётчик не накручивался обновлением страницы |

### Правила (закреплены на сервере)

- Писать на стене может **только её владелец**. Администратор может удалить
  чужую запись (модерация), но не может написать от чужого имени.
- Удаление — мягкое (`deleted`), комментарии остаются материалом разбирательства.
  Удаление чужой записи пишется в журнал действий.
- Чёрный список (`UserIgnore`) в любую сторону закрывает и стену, и подписку.
- Закрепить можно не больше 3 записей.
- Ограничения частоты: 20 записей и 60 комментариев в час, 60 подписок в час.
- Обложки и вложения принимаются только как путь внутрь своего хранилища.

### Постранично по 15

Записи, подписчики и подписки листаются страницами по 15 (`WALL_PAGE_SIZE`),
без бесконечной прокрутки: номер страницы можно запомнить и вернуться, позицию
прокрутки — нет. Ответ всегда содержит `page`, `pages`, `total`.

### Уведомления

- новый подписчик — автору страницы;
- новая запись — всем подписчикам, одной пачкой (`createNotificationsBulk`);
- комментарий — автору записи (себе не шлём).

### Маршруты

```
GET/POST/DELETE /api/users/[id]/follow        статус и переключение подписки
GET             /api/users/[id]/followers     страница по 15
GET             /api/users/[id]/following     страница по 15
GET/POST        /api/wall/[userId]            страница стены / новая запись
PATCH/DELETE    /api/wall/posts/[id]          правка, закрепление, удаление
GET/POST/DELETE /api/wall/posts/[id]/comments комментарии, по 15
POST            /api/wall/posts/[id]/view     уникальный просмотр
```

### Интерфейс

`src/components/profile/ProfilePage.tsx` — шапка (баннер, свечение аватара,
роль, статус, «о себе», бейджи, счётчики), вкладки «Стена / Подписчики /
Подписки», композер, карточки записей, листатель `WallPager.tsx`. Иконки взяты
из `ConnectIcons` проекта: `NewsIcon`, `UsersIcon`, `FriendsIcon`,
`MessagesIcon`, `ClockIcon`, `PinIcon`, `StarIcon`, `CrownIcon`, `ShieldIcon`,
`InfoIcon`, `BookOpenIcon`, `UserPlusIcon`, `TrashIcon`.

## 3. После развёртывания

```bash
npx prisma migrate deploy
npx prisma generate
```

Без этого новые таблицы не появятся и обращения к стене вернут ошибку.
