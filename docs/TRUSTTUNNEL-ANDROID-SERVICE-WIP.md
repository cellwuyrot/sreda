# Android TrustTunnel: исторический эксперимент

> Актуальное подключение подписчиков и условия сборки: `TRUSTTUNNEL-1.2-DEPLOY.md`. Ниже — исторический снимок пилота.

Историческая запись на момент подготовки пилота: тогда сервис и мост были debug-only, подписочный контур и глобальное переключение ещё отсутствовали. Это описание superseded текущей реализацией из `TRUSTTUNNEL-1.2-DEPLOY.md`: TrustTunnel service/bridge теперь подключены к release source set; доступ и глобальный провайдер управляются сервером. Физическое устройство и подписанная release-сборка всё ещё требуют проверки.

Профиль выдаётся по POST с новой проверкой аккаунта и аудитом; секрет не выводится на экран. Мост принимает сообщения только из основного фрейма доверенного origin. Это не защищает от XSS на доверенном сайте; проверить безопасность сайта и журналов. Конфиг в памяти содержит пароль, уничтожение памяти не гарантировано. Отзыв выдачи не отзывает уже выданный пароль на Endpoint.

`apps/android/app/libs/trusttunnel-test.aar` собран локально из официального TrustTunnelClient v1.1.12, commit `067deb837ed994d6ae902e3bb40b69f6266af216`; SHA-256 `22033cea3f93c379071563073116ad7db1120049d1875eace39c789579efcc62`. Исходная лицензия проекта находится в `docs/licenses/TrustTunnelClient-1.1.12-APACHE-2.0.txt`; проверить также условия всех включённых транзитивных компонентов перед распространением. AAR пока содержит только **arm64-v8a**, поэтому APK/AAB всех вариантов ограничены этой архитектурой, Android 8.0+. Это локально собранный SDK для интеграции; включение в release source set добавлено в текущем обновлении, но подписанный официальный/production APK ещё не собран и не проверен. Профиль намеренно привязан к `turn.trioz.ru` и `170.168.18.20:8443`; изменение адреса потребует обновления валидатора и сборки. TCP/HTTP2, TLS-проверка не отключается.

Для исключения конфликтов проверяется состояние Amnezia и запрос системного разрешения. TrustTunnel защищает свои исходящие сокеты через `VpnService.protect`; трафик самого приложения не исключён из VPN. Локальные/LAN диапазоны исключены из маршрутов. При отключении VPN Android может вернуться к обычной сети; kill switch не подтверждён на устройстве. Состояния, гонки при отказе разрешения, lifecycle, сеть, сертификаты, DNS, маршруты, отзыв и секреты остаются для реальной проверки и доработки. Логирование SDK перенаправлено в пустой обработчик; полный аудит логов ещё нужен.

Приведённые выше результаты относятся к старому debug-only снимку. В текущем архиве source set и зависимости дополнительно подключены к release; после этой правки Android SDK/toolchain и production keystore отсутствовали, поэтому новая release-сборка не выполнялась.
