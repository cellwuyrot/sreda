# Проверка обновления TZ.Connect → Business

## Автоматические проверки
- Полный набор основного проекта: 2480 тестов в 180 файлах — пройден. Включены серверные маршруты, компоненты, общие библиотеки, чистые части desktop shell и VPN agent.
- TZ ID: 8 тестов — пройдены.
- После финальных косметических изменений отдельно повторены затронутые компоненты и каталог (38 тестов в 7 файлах).
- TypeScript основного приложения — без ошибок; production-сборка повторно проверяет типы.
- Полный lint — без ошибок; заключительный прогон выполнен отдельно после финальных изменений.
- Production-сборка monorepo (shared + web) — успешна. Существующее предупреждение Next.js об устаревающем имени middleware не блокирует сборку.

## Новые сценарии
- Авторизация обязательна до чтения предложений; ограниченный аккаунт не получает ссылок.
- Отключённый общий каталог, клиент, неподходящий callback и отсутствие нужных интеграционных scopes не создают предложения.
- Отфильтрованы чужие проекты, скрытые услуги и тип MANUAL.
- Проверяются цены, периоды и способы оформления. Цена берётся с сервера, нет жёстко зашитых 200 ₽.
- Наличие только VPN не создаёт фиктивную покупку Premium.
- Ссылка строго https://business.trioz.ru/subscriptions, открывается отдельно с noopener; произвольные URL из некорректного ответа не отображаются.
- Без подписки TZ предлагает Business, с действующим VPN сохраняет открытие панели подключения.
- Premium с включённым соединением не получает лишнюю покупку VPN.
- Сетевой сбой не превращается в «нет подписки»; есть повторная загрузка.
- Неактивный peer не изображается работающим туннелем.
- Настройки профиля реально используют новый компонент карточек; проверены опубликованная/неопубликованная услуга, действующий VPN и доступ по роли.
- Существующие тесты панели включения и экспорта AmneziaVPN сохранены и проходят.

## Визуальная проверка
Реальные React-компоненты отрисованы локально с тестовыми fetch-ответами и заглушками платформенных API. Проверены меню без подписки, действующая подписка, ошибка доступа, окно выбора услуг, ненастроенный Premium, карточки настроек и меню в светлой и тёмной темах. Размеры: мобильный 390×844 и desktop 1440×1000/1100, для длинных карточек полный снимок страницы. Проверены читаемость, контраст новых кнопок и текста, переносы и отсутствие горизонтального переполнения. Модальное затемнение намеренно перекрывает фон; содержимое прокручивается внутри окна.

Это не сквозной прогон production-сервера, реального TZ ID SSO или оплаты. Внешние банковские запросы, изменения реальных прав, SMTP и реальный нативный VPN не выполнялись. Состояние боевого каталога и совпадение аккаунтов нужно проверить после развёртывания по README.
