# Исправления по результатам ревью

Дата: 2026-09-30

## Реализовано

- Приватная демонстрация экрана после reconnect повторно объявляется только после `voice-joined` и сохраняет allow-list.
- Плашка «Идёт трансляция» получила отдельную drag-ручку и ограничение перемещения границами viewport.
- В календаре добавлено удаление из формы события; просмотр для пользователей без прав стал read-only.
- Календарный API валидирует диапазоны и `end >= start`, а многодневные события выбираются по пересечению интервалов.
- Для личных сообщений добавлен rate limit 30 запросов/мин.
- Пустые сообщения с `attachments: []` отклоняются в каналах и DM.
- PATCH/DELETE сообщений повторно проверяют актуальный доступ; для DM также проверяются бан и business lock.
- Удаление DM очищает текст, вложения и ссылку на сообщение-ответ.
- Удаление ответа ветки атомарно уменьшает `threadCount`.
- Автоответ DM защищён от конкурентного дублирования условным update.
- Исправлена блокировавшая production-сборку типизация `MediaStreamTrack`.

## Результаты проверки

- ESLint: успешно.
- Production build (`npm run build`): успешно.
- Целевые регрессионные тесты: 19/19 успешно.
- Полный Vitest: 2049 успешно, 20 ошибок в ранее существующих тестах вне изменённых модулей (VPN desktop, upload, notification grouping, DM list и CloudPayments webhook suite).
- `npm audit`: 36 известных зависимостных уязвимостей (7 moderate, 26 high, 3 critical). Автоматический `npm audit fix --force` не применялся, поскольку он может внести несовместимые обновления.

## Предупреждения сборки

- Next.js предупреждает об устаревшем `middleware` convention.
- Turbopack сообщает о широком NFT trace из `api/projects/upload`.
- В тестовой среде не настроен SMTP; попытка проверки localhost:25 завершается `ECONNREFUSED`, но сборка успешна.
